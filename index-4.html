Perakitan & Perawatan Komputer

1. Perakitan PC Sesuai Standar

Memahami prosedur K3LH, pemasangan komponen utama (Motherboard, CPU, RAM, PSU), hingga manajemen kabel untuk sirkulasi udara yang baik.

2. Troubleshooting Hardware

Identifikasi masalah melalui kode beep BIOS, pengecekan tegangan PSU, dan diagnosa kerusakan pada komponen penyimpanan atau memori.

3. Perawatan & Penggantian Komponen

Pembersihan debu secara rutin, penggantian thermal paste processor, dan upgrade hardware (seperti upgrade HDD ke SSD).

Instalasi Sistem Operasi

1. Instalasi Windows & Linux

Mampu melakukan instalasi Windows (10/11) dan berbagai distro Linux (Ubuntu/Debian) menggunakan media bootable.

2. Pengaturan Driver & Partisi

Konfigurasi pembagian storage (GPT/MBR) dan instalasi driver agar perangkat keras berfungsi optimal di sistem operasi.

3. Manajemen User & Basic Command

Pemahaman perintah dasar terminal/CMD (seperti ipconfig, ping, ls, sudo) dan pengaturan hak akses pengguna.

Instalasi & Konfigurasi LAN

1. Pembuatan Kabel UTP

Keahlian dalam teknik crimping kabel Straight-through dan Crossover sesuai standar T568A/T568B.

2. Konfigurasi P2P & Client Server

Membangun komunikasi antar komputer secara langsung maupun melalui server pusat untuk berbagi data.

3. Pengujian Koneksi

Verifikasi kestabilan jaringan menggunakan LAN Tester dan perintah pengujian konektivitas software.

Pengalamatan IP & Subnetting

1. IPv4 Address

Pemahaman klasifikasi IP (Kelas A, B, C) serta penggunaan IP statis dan dinamis (DHCP).

2. Perhitungan Subnetting

Mampu menghitung alokasi host dan network menggunakan metode CIDR untuk efisiensi jumlah alamat dalam jaringan.

3. Penerapan Jaringan Lokal

Implementasi skema pengalamatan IP yang terstruktur pada perangkat-perangkat di jaringan lokal.

Konfigurasi Perangkat Jaringan

1. Konfigurasi Dasar Switch

Manajemen VLAN, pengaturan hostname, dan keamanan port dasar pada perangkat switch.

2. Konfigurasi Router

Penerapan Static Routing untuk menghubungkan network berbeda dan pengaturan layanan DHCP server.

Dasar Cyber Security

1. Konsep CIA Triad

Confidentiality (Kerahasiaan), Integrity (Keutuhan), dan Availability (Ketersediaan data).

2. Ancaman Keamanan

Memahami bahaya virus, malware, phishing, serta teknik hacking yang umum terjadi.

3. Pengamanan Jaringan Dasar

Penggunaan password kuat, konfigurasi Firewall, dan instalasi antivirus sebagai pertahanan utama.
